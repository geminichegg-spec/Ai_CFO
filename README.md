# Atlas AI CFO (hackathon build)

Open `atlas-ai-cfo.html` in Chrome or Edge. It's a single file with no install and no backend. Allow the microphone if you want to talk to Atlas.

## Demo script (about 3 minutes)
1. Load the page and watch the boot sequence. Atlas greets you by name.
2. Click **Morning brief**: books status, decisions waiting, and the #1 priority.
3. Type or say **"record sale 25000 on credit"**. The entry posts, and the KPIs and trial balance update.
4. Click **Trial balance**, which shows Dr = Cr. Then open the Journal and Ledger tabs (T-accounts with c/d and b/d).
5. Click **What's waiting**, then approve "Reclassify laptop" (this was caught by journal-review).
6. Click **Post adjustments** and the final accounts open: Trading A/c, P&L A/c, and a Balance Sheet that agrees.
7. Try "what if sales drop 15%", "collections", "tax calendar", then **Focus mode**.

## Agents (20)
- Accounting (new): journal-entry, ledger, trial-balance, adjustments, final-accounts, journal-review
- FP&A: forecast-model, variance-analysis, scenario-planner, kpi-tracker
- Cash & Treasury: cash-forecast, cash-alerts, bank-feed
- Revenue & Spend: collections, payables, expense-audit
- Tax & Controls: tax-calendar, controls-review
- CFO Office: cfo-briefing, board-pack

All figures are example data for a fictional company, Orbit Traders. "Reset demo" in the Books sheet clears your entries.
